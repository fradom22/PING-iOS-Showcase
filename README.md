PING

A Voice-First Personal Assistant for iOS

PING is a native iOS application independently designed and developed using Swift and SwiftUI.

The project explores a simpler and more intuitive way to manage everyday tasks and reminders through natural voice interaction, intelligent scheduling, and a carefully designed user experience.

Rather than relying exclusively on traditional forms and menus, PING places voice interaction at the center of the experience.

Key Features

Voice-First Interaction

* Create reminders using natural speech.
* Real-time speech transcription.
* Interactive voice interface with custom animations and haptic feedback.
* Keyboard input as an alternative to voice.

Intelligent Reminder Management

* Standard and recurring reminders.
* Location-based reminders.
* Conditional reminders supported by cloud-based functionality.
* Reminder organization and completion tracking.

Native iOS Experience

* Built with Swift and SwiftUI.
* Custom interactive components and animations.
* Light and dark appearance support.
* English and Italian localization.
* Guided onboarding experience.

Cloud Integration

* Cloudflare Workers for backend functionality.
* Cloudflare D1 for cloud-based data management.
* Integration between the native iOS application and cloud services.
